# Verification evidence

Track compact Markdown/JSON reports and required test fixtures here. Screenshots, raw logs and one-off capture scripts stay locally at their existing paths and are ignored by Git. Historical report links to those local artifacts are not available in a fresh clone; no new independent approval is implied by a retained report. The six title masks are test inputs, not disposable screenshots. Preserve local evidence separately before moving or deleting the workspace.

Git cleanup removes generated files from the current tracked tree only. Existing commits and their blobs remain in history. See [cleanup summary](git-cleanup/summary.json).
