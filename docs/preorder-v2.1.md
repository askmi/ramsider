## 2. Визуальный контракт

База: реальный WebKit 402×874 CSS px, DPR3; второй обязательный экран 440×956 DPR3. Оригинальные HTML открываются на том же движке и ширине; сохраняются оригинальные полноразмерные снимки и читабельные локальные фрагменты. Новый пакет имеет собственный CSS viewport scale **1 source CSS px = 1 browser CSS px**: его нельзя уменьшать коэффициентом 402/941 от главной. Старая главная остаётся в своей системе941px.

- Пять supplied TTF побайтово совпадают с `public/fonts`: OpenSans Light300 / Regular400 / Bold700, OpenSansButton400, BankGothic400. Не дублировать шрифты.
- Фон sand #efe4d3, paper #faf7f2, заголовки #261d18, body #5d5149, source label #8b6b4f (3.87:1 на sand → интеграционный AA override #805f44), line #d6c3aa, gold #b58c4e.
- Основной текст22px/1.22/300, подписи17px/1.4/400; h1 clamp(60px,16vw,68px), h2 clamp(42px,11vw,50px), h3 28px. Сохранять authored регистр бренда и продуктовый English Title Case заголовков; не применять CSS text-transform к локализованным заголовкам.
- Reserve/product/compare: мобильные поля18px, `.wrap` максимум1080px; юридические20px/880px. Desktop исходника имеет48px поля, reserve/model breakpoints801/1100px; legal700px, compare600px. Контент адаптировать без горизонтального overflow.
- Pills64px, OpenSansButton20px; Ivory/Black Glass gradients, borders и тени из источника. Input60px, label17px, checkbox/radio26px с целевой областью44px и видимым focus.
- Никаких fixed/sticky панелей. Safe-area top/bottom/inline учитываются без изменения основной композиции при нулевых inset. Reduced motion отключает плавные перемещения.
- Глобальный CSS главной не должен влиять на absolute overlay, pills, headings или фон новых страниц. Стили пакета изолированы. Растров в пакете нет; существующая главная/арт не перекодируются.

Общий age gate из источника неполон; form18+ обязателен, а подключение глобального возрастного барьера не расширяет без отдельного продуктового решения поведение уже работающей главной. ## Фактическая реализация и проверка — 24.10.2026

Все99 новых языковых document URL статически генерируются Next.js (общая сборка114 страниц). Редакционная HTML-структура и переводы остаются Server Components; клиент получает только небольшой контроллер формы и нужные ему сообщения. Запросов к API/базе нет, поэтому request-time SSR не добавляет нужной свежести. Форму с query моделью активирует клиент, как исходный HTML; до JS управление заблокировано.

Исходные страницы и оба обязательных телефона реально сняты в WebKit.
