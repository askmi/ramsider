## Image Specifications

### Format
- Primary: WebP
- Fallback: AVIF (automatically generated by Next.js)

### Quality
- Hero images: 90
- Product cards: 85
- Feature details: 85

### Optimization
All images are automatically optimized by Next.js Image component with:
- Responsive srcset generation
- Lazy loading (except hero)
- Blur placeholders
- Modern format conversion

## Replacing Placeholder Images

1. Export renders from Figma/design tool at 2x resolution
2. Optimize with imagemagick or similar:
   ```bash
   convert input.png -quality 90 -define webp:lossless=false output.webp
   ```
3. Place in `public/images/products/` directory
4. Restart development server
